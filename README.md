# Generalized tic tac toe game
 Uses arrays to represent the game board, and combined with generalized checking algorithms, and a simple opponent algorithm, allows for a tic tac toe game board with width/height up to 9.

![3x3 game](images/3x3%20game.png)
![9x9 game](images/9x9%20game.png)

## Running
Run the 3x3 executable using:
```bash
./src/tic_tac_toe_any
```
Or edit the W and H constants defined at the beginning of the source code file and recompile.
